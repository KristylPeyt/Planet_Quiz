# 🪐 Planet Quiz
<p>
  A simple Android quiz application about the planets in our Solar System.
</p>

## 📱 About the App

Planet Quiz is an Android application that tests the user's knowledge about the Solar System through multiple-choice questions.

The app displays a question with eight planet choices. After selecting an answer, the app shows whether the answer is correct or wrong, along with the correct answer and an explanation.

## ✨ Features

* 🪐 Three Solar System questions
* 🌎 Eight planet choices
* ✅ Correct and wrong answer feedback
* 💡 Explanations for each question
* 📊 Question progress indicator
* 🔄 Next Question button
* 🎨 Space-themed user interface
* 📱 Android XML layouts and Fragments

## ❓ Questions

The quiz includes:

1. **What is the largest planet?**

   * Answer: Jupiter

2. **Which planet has the most moons?**

   * Answer: Saturn

3. **Which planet spins on its side?**

   * Answer: Uranus

## 🛠️ Technologies Used

* Kotlin
* Android Studio
* XML
* Android Fragments
* Git & GitHub

## 🎯 Purpose

This project was created as an Android development activity to practice:

* Creating Android user interfaces
* Using XML layouts
* Working with Fragments
* Handling button clicks
* Passing data between Fragments
* Using Git and GitHub for version control
